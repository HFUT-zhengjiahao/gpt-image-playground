# 工作区备份（2026-09-19）

画布结构和历史记录平时只存在**浏览器 localStorage** 里，清空电脑或重装浏览器就会丢失，
所以在这里留一份可读、可恢复的副本。

| 文件 | 内容 |
| --- | --- |
| `canvas-*.json` | 每块画布的完整节点数据（与界面「更多 → 导出」同格式） |
| `history.json` | 历史记录元数据（prompt / 模型 / 费用 / 时间） |
| `preferences.json` | 界面偏好（默认模型、质量、尺寸、视图、侧栏状态） |

## 怎么恢复

1. 启动项目，打开画布页
2. 左侧栏 **新建画布** 建一块空画布
3. 工具栏 **更多（…）→ 导入**，选择对应的 `canvas-*.json`
4. 图片文件不在这个仓库里（体积太大、且已被 .gitignore 忽略）。
   要先恢复 `generated-images/` 目录，否则节点会提示「图片已丢失」。
